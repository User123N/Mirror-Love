# Condiciones de uso — borrador para adaptar

1. Usa MirrorLove solo con cuentas y dispositivos propios o con autorización expresa de sus titulares.
2. La persona emisora elige qué pantalla compartir y debe aceptar el permiso del navegador.
3. No uses el servicio para vigilancia encubierta, acoso, suplantación, acceso no autorizado o difusión de información privada.
4. No intentes eludir los controles del navegador o del sistema operativo.
5. El servicio puede interrumpirse por condiciones de red, navegador, sistema operativo o proveedor TURN.
6. El operador debe adaptar estas condiciones a su entidad, jurisdicción, edad mínima, soporte, suspensión de cuentas y obligaciones legales antes de ofrecer el servicio públicamente.
